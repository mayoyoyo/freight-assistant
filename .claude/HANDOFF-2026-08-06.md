## Traps and non-obvious facts (hard-won this session — don't rediscover)
- **Dataset decoys:** `rate_quoted_usd` is null in ALL 274 emails (rates live in body text only); `equipment_mentioned`/`intent`/load refs can contradict body content (e.g. email CE0074: subject "Box Truck", field says "Refrigerated"). NEVER treat pre-labeled fields as truth — extract from raw text, store fields as `stated_*`, flag discrepancies. This is the hidden test.
- **Compliance angle:** 2 carriers null MC, 3 null + 2 CONDITIONAL authority_status, 1 insurance expired before 2026-05-25. Recommendations must surface these.
- **Temporal grounding:** dataset frozen ~2026-05-25 → `REFERENCE_DATE` constant injected into system prompt; never `new Date()` in agent code (also cache-hygiene).
- **Opus 5 API quirks:** rejects `temperature`/`top_p`/`top_k` entirely (→ judge "temp 0" convention impossible; use structured binary output + repeat-stability, documented as ADR); thinking is ON by default (budget `max_tokens` accordingly); no assistant prefill.
- **Eval methodology:** grade outcomes not tool-call sequences; TPR/TNR + kappa, never raw agreement; judge tuned ONLY on calibration set (half deliberately corrupted), never on cases.jsonl; report Wilson 95% CI (at n=24 it's ~30 points wide — publishing that width IS the rigor signal); k=3 runs is our own addition, not the guide's.
- **FTS + numbers:** Postgres tsvector handling of number-dense tokens (MC numbers, load IDs) must be verified in Phase 1; fall back to ILIKE/trigram column if they don't tokenize searchably.
- Audio: mono 16kHz Int16, 60–90s, 55 files ≈ 70 min total, ~$0.77 Deepgram.
